For Anchor to talk back to you like a friend, it needs a Claude API key. This is yours — stored only on this device, no one else sees it.

1. Go to console.anthropic.com and sign up
2. Add a payment method (small starter credit covers months of check-ins)
3. Go to "API Keys" → "Create Key"
4. Copy and paste it here
